Estándar visual Taller

Tipografía Barlow Condensed para títulos y precios, Barlow para texto. Fondo gris acero, tarjetas blancas, negro carbón para encabezado y pie, naranja de seguridad para la acción principal. Verde, ámbar y rojo solo para estados. Botones y áreas táctiles de 44 px o más, foco visible con contorno naranja. Los paneles internos usan el mismo sistema con menú lateral.
